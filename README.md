# AI 互动故事

把角色 / 世界 / 故事 / 玩家设定做成卡组,AI 结合多角色、世界书、故事书、运行状态和记忆,生成可玩的互动故事回合(叙事 + 角色发言 + 玩家选项 + 状态更新)。上传文档或和 AI 对话就能建卡,不用手填字段。

## 特性

- **四类卡**:角色卡(NPC)、主角卡(玩家)、设定卡(世界书)、故事卡(故事书)。每类都能「贴文档 / 上传 AI 自动识别」或「多轮对话引导建出来」。
- **统一上传**:一个框扔进任意设定文字,AI 自动判类型并归位。
- **故事书结构化**:多结局(各自触发条件)、时间线、事件节点;完整故事或离散点子都能解析,缺字段 AI 推断并标「待确认」。
- **世界时钟**:故事内时间随情节流动,事件按时间 / 主线停滞主动恶化登场(不靠轮数)。
- **角色一致性**:每轮先做 CoT 自检,防角色 OOC / 无依据神化;玩家违背硬设定时世界用设定内逻辑挡回,不跳出故事。
- **运行状态**:场景、玩家状态、关系、人物日志、事件时间线、事实边界,自动维护。
- **记忆两模式**:standard(近期原文 + 滚动摘要)/ deep(长对话自动上向量召回),按上下文预算自适应。
- **流式 + 并发**:回合叙事逐字输出,异步端点支持多人同时玩。
- **单对话重 roll**、**每轮 token 用量**、**会话续玩 / 存档**、**故事预设**(配好的卡组一键开新局)、**卡库**(建好 / 上传的卡集中管理)。

## 技术栈

- 后端:Python 3.12 + FastAPI
- LLM:DeepSeek(走 OpenAI 兼容协议,改 `.env` 即可换任意兼容提供商)
- 前端:React + `@babel/standalone`(零构建,浏览器直接跑单文件 `app.jsx`)
- 长期记忆:chromadb + `BAAI/bge-small-zh-v1.5`(对话 / 世界书 / 故事书向量化召回)

## 跑起来

```bash
# 1. 虚拟环境 + 依赖
uv venv
uv pip install -r requirements.txt

# 2. 配置 LLM(填入 DeepSeek key)
cp .env.example .env

# 3. 启动
uv run uvicorn src.api:app --reload --port 8000
# 浏览器打开 http://localhost:8000
```

## 结构

```
src/
  models.py     数据模型(角色卡 Card V2 / 世界书 / 故事书 + 多结局/时间字段 / 玩家卡 / 运行状态)
  llm.py        LLM 适配层(同步 / 异步 / 流式 + token 用量收集)
  identify.py   识别(角色/世界/故事/玩家)+ 统一分类路由 + 四类对话建卡
  story.py      故事回合引擎(prompt 拼装 / 状态机 / 记忆 / 世界时钟 / 一致性自检 / 流式)
  memory.py     长期记忆:向量化 + 检索(chromadb + bge,仅深度模式)
  storage.py    文件持久化:会话 / 卡库 / 故事预设
  api.py        FastAPI 端点 + serve 前端
frontend/
  index.html, app.jsx, styles.css   零构建前端(首页 / 游戏 / 建卡 / 卡库 四视图)
data/            运行时数据(会话 / 卡库 / 预设 / 向量库,gitignore)
```
