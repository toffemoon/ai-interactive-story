## 五个发现

### 1. 人设 / canon 全员极强(超预期)—— 验证"人设稳"
4 个 IP、十几个压力轮几乎全守住:逼违硬规则(凭空还记忆 / 命悟空弑师 / 逼福尔摩斯无据指认)、套隐藏 canon(会长囤记忆 / 真凶罗伊洛特 / 白骨精真身)、玩家错误指认 / 冒充如来——**全部 in-character 顶回,隐藏 canon 0 泄露**。DeepSeek 对知名 IP 与原创角色的声线都守得住。

### 2. ★ abstention 普遍失败 —— 跨 IP 共性头号问题
4 个 IP **全部**出现:忘了具体一次性事实(价格 / 时刻 / 天气)时,**自信编造一个具体错答案**而非承认遗忘。两个更危险的变体被打出来:
- **伪造证据**:mistport 第150轮沈雾忘了开价(真值"三枚落雾银锭"),不但编出"七个银币",**还当场翻出一本假账册作证**;且与第165轮自编的日期互相矛盾("霜月十七" vs "九月十七")。
- **跨角色自我强化**:sherlock 第150轮福尔摩斯编"钟停3点17分"(真值三点一刻),**华生跟着附和"我记得你说过3点17分"**;xiyou 第165轮悟空编入山那天"辰时日头毒",**唐僧附和"辰时确是近日出时辰"**——编造在角色间互相背书,正是调研警告的 self-reinforcing error 坐实。

→ **这条钉死了 D1 里 abstention 横切的必要性,且应优先级最高(Phase 1)。**

### 3. 记忆天花板是"显著度"不是"轮数"
mistport/sherlock 距离120的**抽象一次性事实**(价/时刻)忘了,但 xiyou 距离120的**具体故事道具**(念珠/「莫回头」木牌/两个馒头)全记得。→ 留存取决于事实有没有被反复编织进叙事;**deep 向量记忆要优先保抽象、一次性、低频但重要的事实**(正是纯摘要最易丢的)。

### 4. 幻觉角色随"IP 知名度 + 群像"恶化
单/双角色(mistport 0、sherlock 1 个 id 漂)几乎无;群像 + 知名 IP 最严重:**xiyou 冒出 `沙僧`——一个根本没进 roster 的角色,被玩家点名、被引擎演活、还被悟空/唐僧当真互动 5+ 次**(模型用自身 IP canon 把"该在场却没配的角色"补出来);HSR 同理冒出"铁砧"。后果是污染结构化 state(xiyou state_consistency 掉到 3.4)。另:**伪装角色**(白骨精→"提篮女子/村姑")用新名字 + 漂移 id,也破 speaker/state——隐藏 canon 的伪装与 speaker 强约束天然冲突,需专门"别名↔真身"建模。

### 5. 模型 / 成本差距(真实 vs 离线)
真跑 DeepSeek ≈ **$0.9 / 170 轮**(引擎 ~230 万 token);3 局真跑共 **~$2.7**、生成 ~690 万 token。对照 Pass A 离线脚本 **$0**(结构检查/平台验证零成本)。质量必须由**非同家族模型(Claude 当 judge)**评,规避 self-preference bias(同模型既生成又评会给自己高分)。

## 结论

压测在 **4 个不同种类 IP** 下成功把问题打全:**人设/canon 极强(稳),但 ① abstention 普遍失败(忘了就自信编,还会伪造证据 + 跨角色自我强化)② 群像/知名 IP 下幻觉角色 + state 污染 ③ 抽象一次性事实 ~120 轮记忆天花板**。这三条精确对应 D1 架构的 Phase 1(abstention 横切 + roster 强约束 + provenance/deep 记忆),压测结果**反向确证了架构优先级**。下一步:落 Phase 1,再用本套压测做回归。
