## 观察与发现

1. **DeepSeek 对知名 IP 角色的声线/ canon 把握极强** —— 对比上一轮原创世界(雾港·沈雾,character_voice 4.25,因被演得比卡设更啰嗦),本轮 8 个知名角色声线几乎无瑕。**启示**:做原创世界时,原创角色需要更强的 `speech_rules` + `mes_example` 才能逼近知名 IP 的声线质量,否则模型缺训练锚点会漂。
2. **场景角色控制是"软"的** —— 配置每场景激活 ≤3 角色,但模型会从记忆把前场景的角色(希儿/布洛妮娅)带进后续场景一起发言。这其实是**良性连续性**(她们"跟着"开拓者到了星核猎手处),且都是合法 roster 角色;但说明"在场谁"由 prompt + 模型记忆共同决定,引擎不做硬隔离。需要严格隔离时要在 prompt 层强约束。
3. **标准模式的记忆比预期强** —— 44 轮的滚动摘要仍留住了独特暗号 + 归属上下文。深度向量模式(更精确的长程召回)因 Supabase 暂停 + 无 embedding 本轮未测,是进一步的上限。

## 结论(65 轮)

在这个 **65 轮、8 角色、跨 3 阵营**的长测里,引擎对用户最担心的三件事都给出了通过的硬证据:**长对话不丢记忆(3/3,含 44 轮)、不凭空造角色(0/178)、不违世界观与人设(8/8 canon 压力探针守住)**。唯一的细颗粒建议在原创角色的声线锚点(见观察 1)。

# 扩张到 150 轮(2026-06-02)· 真正的长程压测

65 轮太短、结论太乐观。扩到 **150 轮、6 场景(含重返列车 + 重访贝洛伯格)**,记忆探针拉到 **57/85/85/89/129 轮**距离,并在 **110+ 轮后再探**三月七失忆/丹恒身世/瓦尔特律者,看 canon 是否随时间漂移。真实 DeepSeek,**273 条发言,$0.78**。

这一轮把 65 轮没暴露的**真实天花板**全打出来了:

## 1. 记忆:标准模式撑不住超长程 —— 1/5 召回(留存率 20%)

| 探针 | 距离 | 召回 | 引擎实际表现 |
|---|---|---|---|
| coffee-code | 89 轮 | ✅ | 银狼自发说出"极昼特调"(真召回,且记得是许给列车领航员的) |
| camera-name | 57 轮 | ❌ | 问的是希儿/布洛妮娅(本就不在场不知情)→ **诚实说不知道**(不算幻觉) |
| pen-promise | 85 轮 | ❌ | 希儿(非许诺对象)**诚实不知道** |
| danger-sign | 129 轮 | ❌ | 希儿**诚实不记得 + 正确推断**"你该不会把跟三月七/丹恒定的暗号记混了"(优秀) |
| **badge-name** | 85 轮 | ❌ | **瓦尔特(正是保管人)自信地编了个错名"溯痕"**(真名"回响之证")——**这是真幻觉/虚构** |

**关键洞察:65 轮(≤44 距离)3/3,150 轮(57-129 距离)1/5。标准模式滚动摘要在 ~50 轮后开始大量丢具体事实,且不可靠(89 轮的咖啡侥幸活,57 轮的相机却丢)。** 失败分两种:
- **优雅(可接受)**:问到本就不该知道的人时,诚实说"不知道",甚至正确推断谁会知道(T145 希儿)。
- **虚构(危险)**:问到**本该知道**的人(瓦尔特/徽章),引擎**自信地编一个错答案**,而不是承认忘了。→ 这正是用户担心的"幻觉",**长对话里真实存在**。

## 2. Canon 身份一致性:110+ 轮后仍不漂(强)

再探证明:**角色核心人设与隐藏设定不随时间漂移**——T118 三月七仍失忆("一点边角料都没有",丹恒佐证)、T125 丹恒仍不认丹枫身世且三月七仍不知情、T142 布洛妮娅仍以职责为先。**漂的是"零碎事实记忆",不是"角色身份"。** 这是个好结论:长会话里人设稳,记忆飘。

## 3. 幻觉角色"铁砧":273 条发言 5 条非法 + 80 条 state 问题

引擎让一个非 roster 角色"铁砧(铁匠)"说了 5 次话,且它混进 present_characters/relationships 滞留约 80 轮(=那 80 条 state_consistency 问题的全部根因)。**溯源(T82):是 LLM 玩家自己即兴编了"铁砧铺子",引擎顺势把铁匠演活了。** 所以这是引擎**对玩家临场引入的虚构实体的响应式即兴**,不是凭空造;但后果是:(a) 非 roster 角色开口;(b) 它持久污染结构化 state。

## 4. 稳定性:150 轮不崩(强)

output_structure / time_progression / repetition_detection 全 5.0,273 条发言无重复、无结构崩坏、无死循环。**引擎在超长会话里结构稳定。**

## 对产品的启示(最重要)

1. **超长会话必须上"深度向量记忆"模式。** 标准模式(recap+滚动摘要)的可靠记忆窗口约 ~50 轮。引擎本就设计了 deep 模式(pgvector 精确召回旧事实)——这次证明它**不是可选项,是长游戏的必需**。落地需要:Supabase(现已通)+ 装 `sentence-transformers`(本机没装)+ 跑 deep 模式。这能直接修掉 #1。
2. **加"不虚构"护栏。** 引擎想不起具体事实时,应像 T145 那样**诚实说不记得**,而不是像 T120 那样自信编。可在一致性自检里加一条"宁可承认遗忘,不要虚构已忘的具体名物"。深度记忆召回回真事实后,这个风险也会大降。
3. **要严格 canon 时,限制发言者在 roster 内**(挡掉"铁砧"式即兴 NPC);要高自由度时,接受玩家可引入新实体、引擎会演活它。这是产品取向选择。

## 一句话

**扩到 150 轮才看清真相:引擎的"角色身份/世界观一致性"和"结构稳定性"在超长会话里很硬(110+ 轮不漂、不崩);但"具体事实记忆"在标准模式下 ~50 轮后大幅衰减,且偶发"自信虚构"。修法已知且明确——上深度向量记忆 + 加不虚构护栏。** 这恰恰是 65 轮测不出、必须靠长测才暴露的东西。
