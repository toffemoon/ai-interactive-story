# 系统提示卡（导演提示 · 可选覆盖)

> 一张定义**旁白口吻 / 输出格式 / OOC 处理 / 卡片优先级 / 禁止剧透**的导演层卡,作用于整个故事(覆盖引擎默认)。

> **重要定位 · 别误用**:
> - 这些行为**引擎已经内置在代码里、且生产级**(story.py 拼 prompt、CoT 防 OOC、hard_violation 世界内反制都已落地)。**普通作者 / 玩家不需要这张卡**——直接用四书(角色/玩家/世界书/故事书)就行,这正是护城河(不让用户写 prompt)。
> - 本卡是给 **Pro / 导演级用户**的可选出口(对接产品愿景的「Pro 版自己写提示词」),想精细调旁白文风、输出格式、尺度时才用。
> - **引擎现状**:全局系统提示已内置;**per-story 自定义系统提示注入这个口子可能还没有**,要先确认 / 或给引擎加一个「故事级 system 覆盖」字段(改数据结构、得你拍板)。落地前本卡只作设计稿。

> 填法:只填你要**覆盖默认**的项,不覆盖的删掉(留空=用引擎默认)。`<...>` 占位。
