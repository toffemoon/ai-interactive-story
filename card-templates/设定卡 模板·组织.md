# <组织名>（设定卡 · 组织）

> 组织口径:<全名、简称、常被叫什么>。
> 用途:驱动 AI 互动故事引擎,正确呈现该组织相关人物、场景、文书、内部权力与对外关系。
> 核心原则:<这个组织最不能被写歪的一两条,如「压迫感来自制度而非个人恶意」>。

---

## 0. 引擎摘要（必填,结构化)

> 填什么:四行结构化锚点,让引擎一眼抓住这是什么、怎么召回、什么能写什么不能写。

- **一句话锚点**:<这是什么组织、对玩家/剧情是什么、底色一句>
- **召回关键词**:<组织名、简称、关键职位、据点;逗号分隔>
- **知识分层**:public:<角色普遍知道的>;hidden:<元真相/内幕,默认不注入,如「真正目的」「高层秘密」>
- **口吻 / 禁区**:<这组织的人说话调性 + 不能写成什么>

---

## 1. 概览

> 填什么:是什么 + 本质一句话 + 外界怎么看它(支持者 vs 反对者各一句)。不写世界级背景。

<例:一个掌控某资源命脉的商会型组织。支持者视其为秩序的提供者,反对者视其为披着规则外衣的盘剥机器。>

## 2. 宗旨与信仰

> 填什么:它的目标 / 口号 / 信仰外壳。区分「它宣称的」和「它实际做的」——张力在这。

<例:对外宣称「让流通惠及所有人」,实际运作以利息和依赖锁住成员。>

## 3. 结构与权力

> 填什么:谁名义上统治、谁真正掌权、层级 / 部门速览、关键职位(若有)。

<例:名义上由一位德高望重者主持,实权握在几名核心理事手中;下设若干执行部门。>

## 4. 关键人物

> 填什么:核心成员列表,每人一句定位 + 在组织中的归属与关系。详细人格在各自角色卡。

<例:首领——对外的面孔;二号人物——真正决策者;某叛离者——隐患来源。>

## 5. 与其它势力关系

> 填什么:和世界里其它组织 / 阵营的关系,每个一句(盟 / 敌 / 交易 / 博弈)。

<例:与某武装势力是买卖关系,与某官方机构互相忌惮,与某新兴对手暗中角力。>

## 6. 典型成员说话方式 + NPC 原型

> 填什么:统一语气 + 高频词 + 1-2 例句;底层成员给「原型壳」(普通成员 / 中层 / 高层各一壳),不必逐个建卡。

<例:语气克制、爱用契约与数字说话。普通成员壳 / 中层壳 / 高层壳各一段口吻。>

## 7. 剧情钩子

> 填什么:2-4 个能直接开场的局(导演视角)。涉及 hidden 的就近门控,写法:(L3/L4 · 仅 XX 线触发 / 默认察觉不到)。

- <例:玩家被卷入一笔无法偿还的债务,组织开始施压。>

## 8. 召回关键词

> 填什么:可比 frontmatter 更细;切世界书条目时按这些词分条(总览条 + 各部门 / 各人物条)。

<组织名、简称、关键职位、关键据点、标志物……>

## 可选段（按需补,核心组织或玩家关心时再加;不用就删)

### A. 运作机制

> 填什么:它靠什么运转——放贷 / 计息 / 资源循环、入会与退出、叛出的代价。

<例:以借贷计息维系,入会要缴投名状,退出需还清欠款,叛出会被追偿与报复。>

### B. 玩家接口

> 填什么:玩家能和它处成什么关系(玩家视角的关系槽)——入会 / 欠债 / 交易 / 敌对 / 揭黑。

<例:可申请入会、向其借贷、做一笔买卖、与之为敌,或搜集证据揭其黑幕。>

### C. 实力与底牌

> 填什么:资源 / 规模 / 王牌手段,供引擎判断「它做不做得到」。

<例:掌握某关键资源的渠道,养有一批打手,手里攥着多人的把柄。>

### D. 内部裂痕 / 路线之争

> 填什么:组织内的派系张力(非铁板一块)——谁主张什么、谁想取代谁。

<例:守成派想维持现状,扩张派想以武力吞并对手,二者貌合神离。>

### E. 标志物 / 暗语 / 仪式

> 填什么:身份凭证 / 暗号 / 入会或结算仪式(识别锚 + 召回)。

<例:成员持有某种刻记信物,见面对暗号,结清债务时有一道封印仪式。>
