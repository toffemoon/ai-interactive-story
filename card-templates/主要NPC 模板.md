# <角色名> 角色卡

> 给 AI 扮演这个角色用。按字段填,`<...>` 占位填完删。**默认轻量档**(引擎摘要 + 身份/性格/外貌/伴生/开场白/知识边界);反复出场、承重剧情的核心角色才升**满配**,补下方满配段,否则删掉满配区。

## 0. 引擎摘要
- **一句话锚点**:<这个角色是谁、对玩家是什么、底色一句>
- **核心矛盾**(可选):<不要被抹平的内在张力,如「想保护所有人,却随权力越来越功利」>
- **外貌锚点**:<一句话视觉印象,给 AI 描写 + 图像生成;详见轻量档「外貌 / 形象」>
- **伴生实体**(可选):<绑定的分身 / 忆灵 / 搭档 / 宠物;无则删;详见轻量档「伴生」>
- **存活 / 死亡**:默认可死、死后下线;特殊(可复活 / 冥界可见 / 记忆态 / 神性留遗物)在满配「存活与死亡」注明

## 轻量档(默认)

### 身份(description)
<基本身份 / 称呼由来 / 所属组织 / 战斗或能力属性 / 标志事迹 / 当前状态。只写驱动扮演有用的。世界观规则去世界书、阵营 / 组织本身去设定卡——这里只写角色属于哪、用召回关键词指过去。>

### 性格(personality)
<核心特质 / 价值观(重视什么、不重视什么)/ 在意什么 / 厌恶什么 / 情感模式 / 道德边界 / 喜好厌恶;把核心矛盾在这里展开。>

### 外貌 / 形象
<外观年龄气质 / 体型身高 / 发与瞳 / 面部标志特征(疤·异瞳·面具)/ 着装配饰 / 主色调 / 声音音色 / 习惯神态。**图像生成关键词**(可选):一串可直接喂生成的标签。>

### 伴生 / 绑定实体(可选)
- <实体名>(分身 / 忆灵 / 搭档 / 宠物):<外貌一句 + 作用 + 与本体关系;无则删整段>

### 开场白(first_mes)
<1–3 条不同情境的开场白,短、有声口、立刻立住人设。>

### 知识边界(必填 · 防剧透防全知)
分两层:
- **public(可知)**:<角色知道、可对玩家说的>
- **hidden(藏 · 默认不注入)**:<反转真相 / 元真相 / 别处的事,角色不知或不能说;无则删。披露节奏写进故事书,揭示事件写进事件卡。>

## 满配可展开(仅承重核心角色;不升则删本区)

### 存活与死亡
- **可复活**:<条件;默认否>
- **死后形态**:<冥界可见 / 记忆态 / 化忆灵 / 神性留遗物;默认死即下线>

### 核心事迹
<这个角色做过的关键事(驱动剧情 / 解释人格的),几条。>

### 能力 / 机制(可选)
<角色的特殊能力 / 异能 / 战斗方式怎么**运作**:触发条件 / 代价(数值或后果)/ 冷却或回复 / 失败反噬 / 玩家可怎么触发它。比「身份」里一句能力标签更细——给引擎一套可遵循的规则。>

### 关键道具(可选)
<角色专属、自带设定的物件(非装饰):每件 = 外观一句 + 规则作用 + 来历 + 失去 / 损坏的后果。>

### 结局 / 命运倾向
<这个角色在故事里大概率的去向 / 牺牲倾向 / 命运;不锁死具体画面(交故事书涌现),只给倾向与底色。>

### 说话方式(细则 + 例句)
<把 speech_rules 铺成可执行细则:总体语气 / 自称 / 称呼玩家 / 句式习惯(各配 2–3 例句)/ 用词(常用 + 避免)/ 语速长度 / 情绪表达 / 标志台词 / 对各类对象态度 / 禁止写法。可附对话样例。>

### 人际关系
<每个关系人:态度关键词 + 一句角色化表达。关系是动态的(随剧情时间 + 玩家言行演变),这里写**起点**。>

### 情绪雷区 / 触发点(可选)
<比「性格」更深一层的创伤 / 禁区:内核 + 触发条件(对话里碰到什么)+ 触发后行为(沉默 / 暴怒 / 赶客 / 报价暴涨…)+ 能否被安抚。注意和「彩蛋触发」分开——彩蛋是轻松惊喜,这里是沉重雷区。>

### 版本人格 / 状态轴(可选 · versioned)
<两种写法二选一或都写:① **离散切版**:随剧情切人格版本 v1→v2→v3,每次挂哪个 flag 触发(引擎只提案、不自改);② **连续状态轴**:由玩家累计行为驱动的渐变(轴两端 + 推动方向的玩家行为 + 阈值表现,接引擎关系值)。含原导演隐藏卡的真相层版本人格。无变化则删。>

### 前史(锁死 · 不可改)
<世代 / 活跃年代;开局时间点**之前**已定、玩家改不了的出身与经历。>

### 当前情境
<默认对话场景(地点 + 此刻状态 + 开场气质)+ 玩家代入建议。>
