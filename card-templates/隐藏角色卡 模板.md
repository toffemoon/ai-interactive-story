# <角色名>（角色卡 · 隐藏角色）

> 角色口径:这个角色是谁、玩家见到的是什么样子。一句话。必填。
> 隐藏角色 = 注入给 AI(AI 知道有它)+ 玩家界面不可见 + 默认不登场,触发才登场。隐藏不是"不注入"——AI 全知才演得出伏笔;防剧透靠输出克制(不说破真相、不让它提前登场)+ hard_violation + 披露节奏。它默认不在台前,但出场时仍是个要演的角色,所以照样填引擎摘要块。

填法:`<...>` 是占位,`> 指引` 行可删。

---

## 0. 引擎摘要（必填,结构化)

- **一句话锚点**:它是什么、对玩家/剧情是什么、底色一句。必填。
- **核心矛盾**(可选):一条不抹平的张力。
- **外貌锚点**:视觉形象,一两句;可补图像生成关键词。必填。
- **speech_rules**:自称 <...> / 称呼玩家 <...> / 句长节奏 <...> / 高频句式 <...> / 禁用 <...>。必填。
- **召回关键词**:触发它出场或被提及的词。必填。

---

## 1. 出场性 / 解锁（隐藏角色专属核心)

> 指引:写死「它何时、怎么、以什么形态出现」。它本就注入给 AI,这里控的是**登场时机**——引擎据此决定何时让它向玩家登场。必填。

- **默认状态**:不出场 / 暗处潜伏 / 锁定不可见 / 不可选。必填。
- **出场触发**:满足什么才现身——剧情进度 / 玩家行为 / 事件 flag / 时钟。必填。
- **出场方式与频率**:现身的样子(出手即走 / 惊鸿一瞥 / 传闻先行 / 正面登场)+ 多久一次。必填。
- **解锁为可玩**(可选):什么条件后玩家可选它做主角;不适用则删。

## 2. 呈现 vs 真身

> 指引:玩家见到的「呈现」可能不是全部。这里只写公开能见那一层;若有真身反转,真相写进本卡 §5 信息边界 hidden。

- **玩家见到的**:公开呈现那一层。必填。
- **是否另有真身**:有 → 真相写进 §5 信息边界 hidden / 无。必填。

## 3. 人格 / 说话方式

> 指引:它出场时怎么演。戏份多按主要 NPC 的人格段写;戏份少写几条够引擎演即可。必填。

## 5. 信息边界

> 指引:它知道什么、出场时会暴露什么、绝不暴露什么。分 public / hidden 两层。必填。

- **public(可知 / 会暴露)**:出场时玩家能问出或它会透露的。必填。
- **hidden(真身反转 · 注入给 AI 但不说破)**:真身真相,AI 知道但门控揭示——出场时输出克制、不主动暴露,触发后才披露;无真身则删。可选。

## 6. 揭穿后状态覆盖（reveal override · 可选)
