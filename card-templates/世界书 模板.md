# <世界名> 世界书

> 每条目为关键词触发条目,直接喂给 AI 互动故事引擎。按 §1 单条目格式逐条写,按来源分组(§2)。`<...>` 是占位,`> 指引` 行可删。
> 教学版 vs 上传版:实际上传给引擎时只保留 §2 的条目本体,格式说明与图例不上传。

---

## 1. 单条目格式

```
## <条目标题（人读用,不注入)>
- 关键词: <词1>, <词2>, <词3>          # 玩家真会说的词 + 标志性专名,多同义词
- 来源: <world | rule | location | figure | race | org>
- 可见性: <public | hidden>            # public 可注入可被 NPC 说出；hidden 元真相,默认不注入
- 触发: <关键词 | 向量 | 常驻>          # 可选,默认关键词
- 优先级: <10 | 9 | 5>                # 可选,token 预算内排序,数大优先
- 硬canon: <是 | 否>                  # 可选,默认否；标「是」=世界铁则,引擎拒绝违背
- 内容: <独立完整的一段。只有这段会注入,标题和关键词不注入。一句话讲清这一件事。>
- 给AI指令: <可选,不外显的行为约束。和「内容」分开——内容是会被叙述/角色说出的设定；这里是引擎的执行规则,不进叙事。>
```

**字段说明**

- **内容** = 会注入、可被叙述或角色说出的设定描述。
- **给AI指令** = 不外显的行为约束,引擎读、不进叙事。例:「此人绝不主动说出自己的过去,除非玩家拿出证物」「提到此地时永远带一股潮湿腐烂的气味」。每条目可选填。
- **硬canon: 是** 时,必须补一句违背反制——违背时引擎怎么处理:纠正叙述 / 让行为失败 / 给代价。

**两条铁则**

- **standalone**:每条「内容」自足,脱离上下文也读得懂。不写「如上所述」「见前文」「同上」。
- **一条一事**:一条只讲一件事。别一条塞全部——会超预算、被错误关键词触发、难更新。宁可多拆几条。

## 2. 条目（按来源分组）

> 同来源放一组,顺序建议 world/rule → location → figure → race/org。下面每组一条占位示范,照着加。

### 世界与规则（world / rule）

## <世界名>
- 关键词: <世界名>, <世界别称>, 这个世界
- 来源: world
- 可见性: public
- 内容: <一句话定义世界 + 最核心的世界观骨架(谁创世、当前大灾劫、核心机制)。新玩家落地第一条。>

## <世界铁则,如「魔法/神权代价」>
- 关键词: <机制名>, <相关词>
- 来源: rule
- 可见性: public
- 触发: 常驻
- 优先级: 9
- 硬canon: 是
- 内容: <一条角色和叙事都不能违反的硬规则。设常驻,每轮注入,锁住世界不跑飞。>
- 给AI指令: <违背反制:角色试图违反此则时,引擎让该行为失败并在叙事中点明代价,不允许"成功破例"。>

## <元真相,如「世界的本质」>
- 关键词: <真相相关专名>
- 来源: rule
- 可见性: hidden
- 内容: (元真相·普通角色不知)<揭示后才存在的炸弹。默认不注入,剧情推到才由叙事引入。>
- 给AI指令: <披露条件未到前,NPC 不得知晓也不得暗示此真相。>

### 地点（location）

## <地点名 · 别称>
- 关键词: <地点名>, <别称>, <标志区域>
- 来源: location
- 可见性: public
- 内容: <这地方是什么、供奉/归属谁、现状一句。供"按当前所在地召回"——玩家在这,这条就注入。>

### 人物（figure）

## <角色名>
- 关键词: <名>, <别称>, <标志物>
- 来源: figure
- 可见性: public
- 内容: <世界书里的人物条 = 给引擎"提到这人时知道他是谁"的速写,不是完整人格。一两句:身份 + 一个记忆点 + 当前处境。hidden 真相另开 hidden 条。>
- 给AI指令: <可选,如"此人绝不主动说出自己的过去,除非玩家拿出证物"。>

### 种族 / 组织（race / org，按需）

## <种族或组织名>

- 来源: <race | org>
- 可见性: public
- 内容: <这个群体是什么、和世界什么关系。>
