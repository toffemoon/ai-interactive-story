# 次要NPC —— 已取消独立卡(2026-06-08)

> **次要NPC 不再单独建卡。** 一般 / 路人 NPC(商贩、守卫、信徒、村民、职员)统一记进**所在地点 / 组织设定卡**的「NPC 原型 / 人员生态」区。

## 为什么取消

原来「主要NPC / 次要NPC / 设定卡 NPC 原型」三档里,中间这档最难稳定区分,执行时容易变成内容全空的名册壳(实测「匹诺康尼校园 次要NPC」就是这样:除名字 / keys / tags 外全空,引擎拿到的是空角色块)。所以收敛成两档。

## 现在怎么放一个非主要 NPC

| 这个 NPC 是… | 放哪 |
|---|---|
| 整类共用一套语气 / 外形的路人(所有城邦守卫、所有商贩) | 对应**地点设定卡 §4 人员生态 / NPC 原型** 或 **组织设定卡 §6 典型成员 / NPC 原型**,给整类一个「原型壳」 |
| 有名有姓、玩家盯上了、需要展开 | 用 [[主要NPC 模板]] 给他**立一张主要NPC 卡**(主要NPC 默认完整,没填的段留空即可) |

## 引擎侧

取消次要NPC 独立卡后,引擎不再需要「次要NPC 名册卡」的单独解析路径;NPC 原型随设定卡引擎一起消费。详见给 Gengyue 的引擎待办。
