# <事件名>（事件卡 · 隐藏事件）

> 一句话口径:这是个什么事件、默认藏着、触发后发生什么。
> 填法:`<...>` 占位,填完删占位符;`> 指引` 行可删。提到别的卡(故事书 / 角色卡)用纯文字写名字,不要打链接。

---

## 0. 引擎摘要（必填,结构化）

> 填什么:给引擎一眼能读的锚点 + 触发概要 + 召回词。

- **一句话锚点**:<这是个什么事件、对剧情 / 结局是什么、底色一句>
- **触发门控**:默认不触发;<满足什么才激活,一句话概括,详见 §1>
- **召回关键词**:<触发它 / 被提及的词,逗号分隔>

---

## 1. 触发 / 解锁（核心 · 门控）

> 填什么:把「它什么时候、被什么触发、触发后置什么」写死——这是事件卡最重要的段。

- **默认状态**:不激活 / 不注入(隐藏)。
- **触发条件**:<满足什么才发生——某个 flag 置位 / 某个前置事件 resolved / 玩家某个行为 / 时钟到点>。
- **触发性**:<一次性(once,触发后置「本事件 done」不再重复)| 可重复(cooldown,隔多久可再触发)>。
- **触发后置位**:<触发后置哪些 flag / fact——这些是喂给故事书结局谓词的接口,是「事件 → 结局」联动的载体>。

---

## 2. 事件本体

> 填什么:触发后实际发生的剧情。情境舞台是给引擎的弹药(可选),不是必经流程。

- **event_id**:<如 EH01,H = hidden,和故事书主事件流区分>
- **摘要**:<触发后发生什么>
- **情境舞台**(可选):<地点气质 / 在场与矛盾 / 危机 / 玩家可玩的>
- **相关地点**:<...>
- **相关角色**:<出场角色名;若牵涉隐藏角色,注明是隐藏角色>
- **玩家可玩的**:<触发后玩家能做的几个方向>
- **可能后果**:<不同选择导向什么 + 置哪些 flag / 信任变化,与 §1 触发后置位呼应>
- **severity**:<1–5,恶化烈度 + 注入优先级>

---

## 3. 对结局的影响（联动声明）

> 填什么:事件卡不自己定结局,只声明「触发我 → 置了什么 flag/fact → 故事书里该解锁 / 改变哪个结局」;对应分支要在故事书那侧补上,否则触发了结局也不变。

- **触发本事件 →** 置 <flag / fact> **→** 故事书应解锁 / 改写的结局:<结局名 / id>。
- **不触发(默认)→** 走故事书默认结局:<默认结局>。
- **配套故事书需补**:在对应故事书的结局段增一条分支 + 谓词读上面的 flag/fact。

---

## 4. 信息边界（防剧透）

> 填什么:只写「触发前要不要瞒着玩家这个事件的存在」。事件牵涉的元真相能不能说,归故事书的事实边界管,不写在这里。

- **触发前**:<是否暗示这个隐藏事件的存在;暗线事件通常绝不暗示,触发即现>。
- **牵涉的 hidden 真相(若有)**:<只标「触发本事件会碰到哪条 hidden,其门控见故事书事实边界」,本卡不复述真相>。

---

## 5. 未触发回响（可选）

> 填什么:玩家错过本事件时,是否在默认结局留一点痕迹 / 暗示——隐藏事件「没发生」本身也是一种叙事。

- <错过后在默认线留什么余味 / 空缺感 / 旁人一句话;不点破它本可发生>

---

## 6. 前置伏笔（可选）

> 填什么:触发前可反复出现、但不点破的细节,给 AI 复用——非必现。

- <可在多个场景零散露出的标志物 / 台词 / 氛围,埋而不挑明>
