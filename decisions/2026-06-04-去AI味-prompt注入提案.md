# 提案:故事引擎叙事「去 AI 味」—— 注入反 AI 写作规则

## 背景
yufei 在测故事界面时觉得引擎生成的叙事 / 台词有"AI 味"(概括化陈述、排比堆砌内心戏、疲劳词)。
参考开源 `awesome-novel-skill` 的「去 AI 味」方法,整理出可借鉴的素材。

## 为什么这是 Gengyue 的决策域
去 AI 味最彻底的做法是改**叙事 system prompt**(`src/` 引擎核心),属架构 / 引擎决策域。
本文件只是**提案 + 素材**,实现与否、怎么注入、要不要压测,由主理人 Gengyue 定。yufei 不擅自动引擎。

## 借鉴来源
- awesome-novel-skill: <https://github.com/modoojunko/awesome-novel-skill>
  (核心:`memory/anti-ai/{genre}.md` 众包的 ❌AI味 / ✅人味 例子库 + `writing-style.md` 风格规则 + prompt 组装时注入反AI规则)
- oh-story-claudecode: <https://github.com/worldwonderer/oh-story-claudecode> (去AI味素材更细,可一起参考)

## 可注入的反 AI 写作规则(草案)
1. 用**具体动作 / 感官细节**替代概括陈述。
   - ❌「他赢得了比赛,全场观众欢呼雀跃」
   - ✅「终场哨响了。他愣在原地,队友冲过来把他抱起来。他的腿软了,没站稳。」
2. 砍掉**排比堆砌的内心戏**,用外部细节侧写情绪。
   - ❌「也许是压力太大,也许是对手太强,也许是自己还没准备好」
   - ✅「他深吸一口气。裁判在低头看表。他活动了一下脚踝,鞋带有点松。」
3. **疲劳词黑名单**(LLM 高频):突然、意识到、某种、仿佛、不禁、一丝、嘴角、缓缓、轻轻……
4. 不元叙事 / 不自我引用("作为 AI"类)。
5. 不替读者总结情绪,留白让画面说话。

## 落点建议(供 Gengyue 选)
- **A 引擎注入**:叙事 prompt 加一段反AI规则 + 疲劳词表,全局生效、最彻底。需压测验证不伤一致性 / 不丢信息。
- **B 内容侧**:塞进故事书 / 角色卡的写作约束字段(弱、per-故事;现有 schema 可能要加"叙事风格"字段)。

## 备注
整套 awesome-novel-skill 是独立的小说创作 harness(多 agent + 记忆 + 9 层 prompt 组装),**不适合直接搬进本互动引擎**;只借鉴其反AI规则与例子库思路。如果要做,建议先小范围 A/B 对照(开 / 关反AI规则,跑同一段剧情看差异 + token 成本)。
