## P0-3 · 次要NPC名册解析缺失(2026-06-08 实测发现)

「所以我出手了」preset 的次要NPC卡「匹诺康尼校园 次要NPC」实测:除 `name` / `keys` / `tags` 外**所有内容字段全空**(`look` / `description` / `personality` / `speech_rules` / `known_public` 全空)。

根因:它是「次要NPC**名册**」格式(一卡 = 多个路人NPC,见 `card-templates/次要NPC 模板.md`),但 `parse_character` 按主要NPC模板段解析、**不认名册结构**,名册里的次要角色内容一条都没 parse 进来,成了空壳。

后果:不只前端显示空(已在 Yufei 侧前端过滤掉空壳卡兜住),**引擎拿到的也是空角色块** —— 这张卡在故事里等于没生效,次要NPC 一个都没真正进引擎。

请补:次要NPC名册的专门解析(名册 → 拆成多个次要角色,或独立名册结构供引擎消费)+ 重新导入受影响 preset。属解析 / 引擎域。
