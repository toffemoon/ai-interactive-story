## 三、外貌(立绘锚点)
- **红橘色乱翘短发** = 苹果果身;头顶**两片带梗叶子** = 苹果的叶+梗,**且是耳朵**。
- **一条狗狗的尾巴**(犬系特征,立绘这张没带到)——加上叶耳,她是"苹果叶 + 犬"的混搭幻想生物。
- **琥珀色眼睛 · 皮肤很白 · 大眼睛 · 圆脸颊**。
- 招牌:**笑起来眼睛弯成月牙**(立绘这张是安静、微委屈的另一面,不是常态笑脸)。
- 碎发上夹**不成套的小发夹**(绿色、蓝胶囊形…)——因为她包里常备替换装、天天换。
- **校服**:衬衫 + V 领毛衣背心,版型偏大偏旧(扣"家里没那么有钱")。
- 斜挎**苹果造型包**(红苹果、中间露芯),手腕还别片小叶子——周边穿戴在身上。

## 四、性格
**很老实憨厚 + 活泼俏皮**,做什么都**有点懵懵的**(呆萌、迷糊但可爱)。心思单纯、不太设防、热情外放,容易被可爱东西击中。
**乐于助人是她的核心**:喜欢帮别人解决问题,**班上同学有事都来找她**(尤其缝补 / 手作)。ENFP 典型:对人和世界有热情、好奇、想往外跑。
- **怕的东西:毛毛虫 🐛**。反差萌——游戏里最爱"啃果虫"这只虫系宝可梦,现实里却怕真毛毛虫。

## 五、说话方式(speech_rules)
- **自称**:多数"**我**",激动/放松时蹦"**俺**"(土气、接地气的反差萌)。
- **语气:很真诚**——直白、热情、不绕弯,带点憨。
- **口头禅:「俺也一样」**(附和别人时最爱说,憨味十足)。

## 六、爱好 / 习惯 / 记忆点
- **苹果**:喜欢关于苹果的一切,**收集苹果周边**(整个人就是苹果主题)。
- **宝可梦**:爱玩,最爱 **啃果虫**(刚好跟"啃苹果"呼应)和 **密集大蛇**。
- **很会缝纫 + 爱做小手工**:**随身带针线包**,常给同学缝缝补补、做小东西——这也是同学爱找她的原因。
- 包里常备**发卡替换装**(每天换不同发夹)+ **针线包**。
- **出门前必在镜子前端详一阵**才走(小仪式 / 在意形象)。
- **喜欢小动物**(→ 去狗咖打工)。
- **爱吃苹果派**(最爱的食物,照样很苹果)。

## 七、背景 / 处境 / 现状
- **出身 / 名字由来**:**妈妈在河边的苹果树下捡到她**(当时还是小小一只)。妈妈嫌"苹狗"太草率,想了一整晚,用**浮萍的「萍」**(呼应捡到她的**河边**)定名**萍狗**——保留"苹果"谐音,又记下被拾起的地方。⇒ 她是**被妈妈捡来/收养**的。
- **妈妈**:苹果王国的普通居民,**纯人类**(萍狗是她捡来收养的幻想生物孩子)。萍狗**知道自己的身世,但没什么特别的纠结**——觉得"现在和妈妈一起过挺好的"。⇒ **情感健康、知足开朗,不是悲情孤儿**(离家去交换反而会带点"舍不得妈妈"的甜涩)。
- 家乡:**苹果王国**(荒海西边的小国,**两位女皇**统治)。
- 家境不宽裕,靠**狗咖打工**贴补。
- **日常**:每天**准时上下学**,路上**和朋友们打招呼**(规律、friendly 的好孩子)。
- **梦想:去大城市看看。原因很纯粹——自己的苹果王国太小了,想出去见见世面。** 地图上离苹果王国最近的大城市是「**帝王之都**」。
- **重要的人:网上的「小牛」朋友**。两人**约好毕业后去大城市见面**——这把"想去大城市"从单纯见世面,升级成**有个具体的人在那头等她**。
- **🔥 当前主线钩子**:学校办**「交换生活动」**——**交换去别的大陆待一整年**,期间**可选在学校上课、或自由探索**(天然的开放世界开局)。**萍狗想参加,正在准备。** 对家境一般、又困在小王国的她,这是出去看世界最现实的一条路。
- 张力:**家境一般 vs 看世界的梦想**——而**交换生名额**就是这条线现在的焦点(能不能去成 = 天然的故事开场)。
