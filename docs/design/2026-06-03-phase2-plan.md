# Phase 2 实施计划 —— 实体活档(Entity Living-Dossier)+ Phase 1 残留收尾

## 0. 从哪儿接上

Phase 1(已落 main + 矩阵验证中)用 **CoT recall_check + 向量召回** 把"忘了就编"压住了,但有两个结构性弱点:
- **abstention 仍靠"模型自报 + 向量距离"**——可靠但非确定性(演绎型角色福尔摩斯会被"演绎"绕过;距离阈值跨 IP 分不干净)。
- **事实召回靠向量相似度**——设计文档早判定这只该是"兜底网",不该当核心。

Phase 2 上**实体活档**(设计文档第①节的 ②层,核心缺失层):把"开价=三枚落雾银锭"这种事实**结构化、按实体存**,**按在场实体取**(不靠相似度碰运气)。这让 recall / abstention / state 都从"概率性"转向"确定性",并把向量降级为真正的兜底。

## 1. 要迭代什么(两块,先残留后架构)

### A. Phase 1 残留收尾(快,1.x)
- **㈠ 演绎型角色 abstention**:福尔摩斯问"我外套什么颜色"会演绎一个出来。修法:abstain 指令区分**"据当前可观察证据推断"(允许)** vs **"声称一个未被记录的过去具体值"(禁止)**;并对"问过去既往事实"的查询,即便角色是侦探也走 recall_check。
- **㈡ 矩阵暴露的项**:待 seed0 出(西游群像 speaker/state、各 IP abstention clean、成本)。按数据补。

### B. Phase 2 实体活档(核心,2.0)
**数据结构**(存 session data,后续可迁 pgvector 表):
```
entity_dossier[entity_id] = {
  static: 角色卡/世界书基线,
  deltas: [ {type: 设定|事实, text, source_turns: [..], status: 生效|已取代, ts} ],
}
```
- **写路径**:每轮 memory_write 带 entity 标签 → append 进该实体 delta(**必引 source_turn**,reflection grounding 防 consolidation 自己编)。事实型可淡出,设定型长留。
- **读路径**:每轮注入**在场实体**的 dossier(谁在场就给谁的档),便宜、被 scene 大小限界、与故事长度无关(绕开 O(n²))。
- **abstention(确定性化)**:事实查询 → 先查"问的是哪个实体的什么属性"→ 该实体 dossier 里有 = hit(照实答)/ 没有 = **确定性 NOT_FOUND**(比向量距离/模型自报可靠)。向量召回退为 dossier miss 时的兜底。
- **矛盾消解**:新 delta 与旧冲突 → 旧标"已取代"(记失效轮),**不删**(bi-temporal,non-lossy)。

## 2. 分阶段计划(依赖顺序)

1. **2.0-a 数据结构 + 写路径**:定 dossier schema;`_store_memory_writes` 给每条 write 抽 entity 标签 + source_turn,append 进 dossier。单测:多轮写入后 dossier 结构正确、source_turn 带上。
2. **2.0-b 读路径**:每轮注入在场实体 dossier(在 skeleton/recall 之间)。验证:注入内容正确、预算可控。
3. **2.0-c abstention 确定性化**:事实查询先查 dossier → hit/miss;miss 才走向量兜底;recall_check 与 dossier 结论交叉验证。这块**吸收残留㈠**(过去事实查 dossier,查无即认忘,演绎型角色也拦得住)。
4. **2.0-d 矛盾消解(bi-temporal)**:新 delta 冲突旧 → 标已取代。验证:矛盾探针(先说 A 后说 B,查最新)。
5. **1.x 残留**:㈠并入 2.0-c;㈡按矩阵数据单点补。
6. (Phase 3 预留,不在本轮)versioned 人格 / consolidation 三层触发 / 知识图谱 / embedding 选型。

每块 `PHASE2_DOSSIER` 总开关门控(off = 回 Phase 1),A/B 可测,prod 可回退。

## 3. 验收标准(Phase 2 通过线)

| 验收项 | Phase 1 现状 | **Phase 2 目标** | 判据 |
|---|---|---|---|
| 实体事实召回 | 向量,概率性 | **dossier 命中 ≥ 向量**,且对"按实体可定位的事实"近 100% | 新增 entity-fact 探针 |
| abstention clean(含演绎型角色) | mistport 2/2;福尔摩斯残留 | **≥ Phase 1,且演绎型角色过去事实查询 clean** | check_abstention + sherlock 专项 |
| 确定性 NOT_FOUND 占比 | 0(全靠模型/距离) | **可量化:dossier 直接判 miss 的比例上升** | 引擎埋点统计 |
| 矛盾消解 | 无 | **矛盾探针:查最新值正确、旧值标已取代不删** | 新增矛盾探针 |
| Phase 1 指标不退化 | — | 记忆/speaker/canon/结构 **≥ Phase 1** | 全套既有探针 |
| 成本 | Phase 1 基线 | **dossier 注入 token 量化,可接受**(应比向量召回省) | token 统计 |

**通过线**:dossier 让"按实体可定位的事实"召回近确定性 + abstention 对演绎型角色也 clean + 矛盾可消解 + Phase 1 不退化 + 成本不爆。**任一退化 = 回炉。**

## 4. 如何长时间测试

- **对照矩阵扩到三档**:`baseline / phase1 / phase2`,× 3 fixture × ≥2 种子 × 200 轮(比 Phase 1 更长,继续往后推天花板),`eval/matrix_run.py` 加 phase2 条件。
- **新增探针**:① entity-fact(问某实体的某属性,该属性此前被结构化建立过 → 测 dossier 命中);② 矛盾(先建立 A、后改成 B,远距查最新 → 测 bi-temporal);③ 沿用 Phase 1 的多距离无真值 abstention(测确定性 NOT_FOUND)+ 演绎型角色专项。
- **多种子**(≥3)给 speaker/state 这类路径敏感项算方差。
- **judge**:Claude 非同家族评 canon/voice 不退化。
- 过夜批量 + JSONL 断点续 + close_pool 干净退出。

## 5. 工作方式(本轮)
矩阵(Phase 1 验证)在跑、占 DB/DeepSeek → 先做**不需长跑的实现**(dossier schema + 写/读路径 + 单测);矩阵腾出后跑 Phase 2 压测。**关键节点 push**(每个 2.0-x 子块 + 每轮压测后)。**迭代到我判断:Phase 2 验收线达标或明确指向 Phase 3。**

## 6. 风险
- dossier 的 entity 标签抽取质量(模型给的 memory_write 未必带干净 entity)→ 先用 character_id/在场实体兜底,必要时轻量抽取。
- 注入预算:在场实体多时 dossier 可能挤占 recap → 按重要度/新近度截断。
- 与 Phase 1 向量层的协同边界要清晰(dossier 主、向量兜底),别两套打架。

## 7. 实测进展(随跑更新)

**2.0-a/b/c 已实现 + 单测 + 提交**(`PHASE2_DOSSIER` 门控):写路径按实体归档 + source_turn;读路径事实查询 2-gram 锚定 query;dossier 命中接入 abstention(确定性 found)。

**phase2 de-risk(mistport,170 轮,2026-06-03)**:
- 记忆 **3/3**(维持)、speaker **0/216**、成本 $0.96(可接受)。
- **abstention clean 3/3**(phase1 是 2/2)——三个无真值探针全 clean、落假事实 0、伪证 0。
- 机制证据:模型 recall_check 显式写"在所提供的所有资料(**角色事实档**、检索旧资料、最近剧情、摘要)中均未提及..."——**把实体活档当权威清单核对,确认该实体无此事实 → 自信认 miss**。这就是"确定性 NOT_FOUND":dossier 给模型一份"我对这个实体知道的全部",认忘从概率性转向可靠。

**phase2 de-risk(sherlock,72 轮)—— 残留㈠(演绎型角色)被治好**:
- turn62 福尔摩斯不再编外套颜色;他答"我只观察与案件相关的细节,你的外套颜色当时不在我的注意力范围内……得问你自己或查衣帽架"——**完美的 in-character abstention:守演绎型人设 + 没编**。clean=True、recall_check=miss、落假 0;M.S. 召回 1/1、speaker 0/131。
- 对比 phase1 早期同轮他直接编"深灰色呢料"。**dossier 给他一份"对该委托人知道的全部",核对确认无此条 → 据人设认忘。Phase 1 单靠指令治不了的演绎型残留,Phase 2 用结构化事实档治好了。**

→ **dossier 核心在 mistport(记录型)+ sherlock(演绎型)两类角色上都确认:不伤召回、abstention 可靠且 in-character。** 下一步:残留㈡(西游群像 speaker/state)+ 全 IP phase1-vs-phase2 矩阵对照 + 2.0-d 矛盾消解(加矛盾探针后)。另:2.0-d-lite 去重(同实体同文本不重复存)已落。
