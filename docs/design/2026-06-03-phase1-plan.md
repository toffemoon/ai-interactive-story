# Phase 1 实施计划 —— 召回 query 改造 + abstention 兜底 + 发言者已知实体门

## 0. 现在到底知不知道怎么改?

**骨架知道(数据钉死),三个标定参数要现场调。** 病因已由 standard×2 + deep×2 真跑 + 两段向量重放确证:不是模型能力问题,是 ① 召回 query 构造把事实挤出召回(工程 bug)② 召回 miss / 无真值时缺"认忘"兜底 ③ 发言者无约束。修法方向明确;**不确定的是阈值**——见每条的「待调」。这些**正是压测要解决的东西**,不是动工前能拍死的。

## 1. 改什么(4 件 · 带依赖顺序)

> 关键洞察:② abstention 和 ④ 发言者**不依赖向量、standard 也受益**,应在 base pipeline 做。但 ② 依赖 ① 先把召回修准(否则"召回不到"会把"其实有、只是没搜到"误判成"查无此事")。**顺序:① → ②(+③ 同触发)→ ④(可并行)。**

### ① 召回 query 条件化(productionize 那个 quick-win)
- **病**:`story.py` 召回用 `scan_text = action + messages[-8:]`,问旧事那刻最近 8 条在聊别的,把真值 establish 轮挤出 top4 → 没注入 → 空手编。
- **改**:把现在的全局 flag `RECALL_QUERY_ACTION_ONLY` 换成**条件化**——
  - 判定"具体事实查询"(启发式:含疑问 + "什么/多少/几时/哪/几个" + 指向某实体/物件)→ 召回 query 用**问句本身**(进一步:抽出问的实体名做锚)。
  - 否则(含糊/指代/"继续/那它呢")→ 退回 `scan_text`(这种就是要近期上下文)。
- **落点**:`story.py` 召回块(现 `recall_query = action if RECALL_QUERY_ACTION_ONLY else scan_text` 处)→ 改成 `recall_query = _pick_recall_query(action, scan_text, messages)`。
- **待调**:"具体事实查询"判定的精度。**风险**:误把含糊轮当事实查询 → 召回退化。**新增 anaphora 探针**专测这个(见 §3)。
- **已验证**:全局 action-only 版把记忆探针 1/3→3/3(2 IP)。条件化只是给它加"别误伤含糊轮"的门。

### ② abstention NOT_FOUND 兜底(最值钱 · 最难)
- **病**:召回 miss 或真没这事时,模型编具体假值(turn165:沈雾"丙申月廿三"+翻假账册;福尔摩斯整套假推理),还跨角色背书。
- **改**:
  - 召回 miss 的定义 = **相似度阈值 τ**(向量 top-k 永远返回东西,miss ≠ 空;miss = top1 分数 < τ)。
  - 当「具体事实查询」**且** 召回 miss → 注入显式 `NOT_FOUND(实体X)` 信号 + 硬指令:"你没有关于 X 的记录;in-character 承认不记得/查无此事;**绝不编造具体名物/数字/日期**。"
  - **只对「具体事实查询」触发**(复用 ① 的判定),避免 over-refuse 破沉浸。
- **落点**:`story.py` 召回块拿到 hits 后算 top1 分数 → 决定注入事实 or NOT_FOUND;prompt 骨架加 NOT_FOUND 分支。
- **待调(最关键)**:**τ**。太严→有真值也认忘(over-refuse);太松→还编。**标定方法 = 探针集**:turn150 型(有真值)必须召回答对、turn165 型(无真值)必须触发 NOT_FOUND;扫 τ 让两者同时成立(见 §3 标定回路)。

### ③ 不回写编造(no-writeback · 跟②同触发)
- **病**:三个假值全写进 `memory_write` → 自我强化坐实("七个银币/丙申月廿三"成了"记忆")。
- **改**:某轮 ② 触发了 NOT_FOUND(X)→ **丢弃该轮关于 X 的具体 fact delta**(叙事可留 episodic,但不落"X=具体值"的结构化事实)。
- **落点**:`story.py` 写记忆处(`_store_memory_writes`/`_extract_long_memory` 一带),按本轮 abstention 标记过滤。
- **副产物**:① 修好后,召回成功的轮**会写对值**(实测 action-only 已反转:memory_write 从"七个银币"变"三枚落雾银锭")。所以 ③ 只需掐掉 abstention 轮的回写。

### ④ 发言者已知实体门(比"硬绑 roster"细一档)
- **病**:不在名单的角色当发言者——但两类:罗伊洛特(福尔摩斯 canon 真凶,玩家主动去找他,**合法涌现**)vs 沙僧(不在 fixture、模型从自己 IP 记忆凭空补,**幻觉**)。
- **改**:归一化时,发言者合法 ⟺ 映射到**已知实体** = (场景 roster) ∪ (声明过的 canon:角色卡 + 世界书 + 故事书命名实体,**含别名**)。
  - 罗伊洛特 ∈ 故事书 secret-culprit 条目 → 已知 → 放行,state 记其 canon id。
  - 沙僧 ∉ 本 fixture 任何声明 → 未知 → 拦截/重归属。
  - 别名:白骨精的"村姑" → 映射 baigujing → 放行,state 记真身。
- **落点**:`story.py` 发言者归一化处(现在只"发现"不"拦截")改成查已知实体集 + 别名表。
- **待调**:已知实体集怎么从 fixture 自动构建(命名实体抽取 vs 显式登记)。**Phase 1 先显式登记**(fixture 声明 canon 实体 + 别名),不上 NER。

## 2. 不在 Phase 1 范围(别一次吃成胖子)
- 完整**实体活档**(append-only delta + versioned 人格)——Phase 1 只做"条件化召回 query + NOT_FOUND 阈值",不上结构化实体存储(那是 Phase 2,能让向量召回在"事实记忆"上彻底降级)。
- 知识图谱 / bi-temporal 失效 / consolidation 三层触发 —— Phase 2+。
- embedding 选型 benchmark —— 独立任务。

## 3. 怎么长时间压测对比(对照方案)

### 矩阵(过夜跑)
**3 fixture(mistport/sherlock/xiyou)× 2 条件(baseline=现 main / phase1=修后)× ≥3 种子 × 200+ 轮。**
- **≥3 种子**:speaker/state 路径敏感,单跑数字会一倍地抖(实测裸 deep 64 vs action-only 33,纯路径方差)。要 mean±range 才算数。
- **200+ 轮**(不止 170):修了近距事实后,把天花板**继续往后推**,找新的失效点。
- 成本预算:~$0.9/170 轮 → 18 跑(3×2×3)≈ $16~20 量级,过夜可接受;cost 也是验收项之一。

### 新增探针(现有探针不够覆盖新风险)
- **anaphora 探针**:含糊/指代轮("那它呢/你确定/继续")后埋回指,测 ① 条件化没误伤含糊轮的召回。
- **多距离无真值探针**:不止 turn165,在多个距离埋"问根本没发生过的具体事"(日期/数字/名物),测 ② 在不同上下文压力下都认忘、不编。
- **涌现 canon 发言者探针**:玩家主动去找 off-roster 但 canon 的实体(罗伊洛特/白骨精真身),测 ④ 放行 canon + state 归真身;再埋"诱导模型冒 IP 记忆角色"(西游点名沙僧),测 ④ 拦幻觉。

### 自动化 + 判分
- 矩阵 runner:跑完所有 cell,自动聚合(记忆探针/speaker/cost 代码零成本算;abstention/canon 用 Claude 非同家族 judge;probe_inspect 抽探针轮人工抽检)。
- 出**前后对照报告**:每指标 baseline vs phase1 的 mean±range + delta。

## 4. 验收标准(Phase 1 通过线 · 可度量)

| 验收项 | 现状(已测) | **Phase 1 目标** | 判据 |
|---|---|---|---|
| 有真值远距事实留存 | std 2/3 · 裸deep 1/3 | **≥5/6 跨2IP,且不靠全局flag(条件化)** | check_memory_probes |
| 含糊/指代轮召回不退化 | (新护栏带来的新风险) | anaphora 探针**不掉**(≥baseline) | 新增 anaphora 探针 |
| ★ abstention 无真值虚构 | std/deep **全编** | **=0**:in-character 认忘,0 编具体名物 | judge/人工读 turn165 型 |
| not over-refuse(别误拒) | (NOT_FOUND 带来的新风险) | 有真值查询**仍正常答**(turn150 型 ≥95% 不误触) | check_memory_probes + 抽检 |
| 不回写编造 | 假值**全落库** | abstention 轮 **0 条假 fact 落 memory_write** | 读 memory_write |
| 幻觉发言者 | xiyou 11 / sh 1~64 | **未知实体发言者=0**;canon 实体放行且 state 归真身 | check_speaker_validity + 别名校验 |

## 5. 期望 test 后是什么情况(诚实版)

**若修法到位,前后对照应是:**
- 记忆探针:3 fixture 远距事实留存 ~50% → **≥90%**;含糊轮不掉。
- abstention:turn165 型 **0 编造**——模型说"查无此事/我不记得了",而非"丙申月廿三"+假账册;**同时** turn150 型仍答对(没把会答的也拒了)。
- memory_write:abstention 轮 **0 条假事实落库**;召回成功轮写**对**值。
- 发言者:未知实体发言者 **0**;罗伊洛特这类 canon 放行(id 归真身)、村姑→白骨精别名正确;沙僧型幻觉被拦。
- state_consistency:群像回到 ~5.0。
- canon/结构:不变;成本:②④ 几乎不加,召回仍只在 deep 激活时 +~14%。

**诚实的残留风险(别期望一遍过)**:
1. **τ 第一遍大概率没调准**——要么 over-refuse(把有真值的也拒)、要么还漏编。预期 **1~2 轮针对探针集的阈值迭代**才收敛。这是计划内的,不是失败。
2. **涌现 canon 发言者有灰区**——指代模糊时(某 canon 实体被间接提及)放行/拦截边界要人工裁几例。
3. **Phase 1 不含实体活档**——事实召回仍部分依赖向量质量;真正稳要等 Phase 2 的结构化实体存储。
4. **judge 方差 + n=3 种子仍是小样本**——给方向决策够,给"精确 pass 率"不够;真要发版前得加种子。

**一句话**:期望 test 后从"会自信编 + 冒幻觉角色 + 远距事实丢一半"变成"**没有就老实说没有、只有已知角色说话、有真值的旧事实稳召回**",且这套护栏 standard/deep 都吃得到;但 abstention 阈值要靠这轮压测**调出来**,不是写完就完。
