# 沉浸式前端设想(书坊版 + 房间版)

> 第三阶段的视觉目标:把整个网站做成一个能"走进去"的空间,功能翻译成空间里的物件和与角色的对话。这里收两版完整设想——新的**沉浸式书坊**(糖沐坐镇,从新手教程的沐言书坊长出来)+ 最早的**沉浸式房间**(原产品愿景里的设想)。两版并列,书坊版是房间版的演进。

---

# 一、沉浸式书坊(新版)

## 1. 一句话

整个网站 = 一间能推门走进去的书店(沐言书坊)。第一视角进店,糖沐(作者 CN)坐在收银台,功能不靠菜单按钮,而靠"在店里走 + 和糖沐对话"完成。

## 2. 进店动线

- **入口**:推门动画 → 走进去 → 落在书店里。
- **糖沐**:收银台后坐着糖沐(作者 CN / OC 店员),是导航与对话的中心。
- **玩家的 CN**:如果玩家做了自己的 CN,可以做出来放进店里走动——把"玩家自己"也放进这个世界。

## 3. 店内元素 → 功能映射

| 店内 | 对应功能 | 说明 |
|---|---|---|
| 推门动画 | 入口 / loading | 一只手推开门,走进书店 |
| **糖沐 · 收银台** | 商城 + 搜索 + 充值 | 镜头来到糖沐面前:显示商城里有哪些故事书;**问糖沐推荐故事 = 搜索**;买咖啡 / 饮料 = **买 token** |
| **书架** | 「我的」(存档 / 故事 / 卡) | 因为是书坊,书架就是自己的存档、故事和卡库 = 现在的「我的」界面 |
| **吧台侧面的门** | 进入游玩 | 选好书 → 走进这扇门 → 直接进游玩界面;刚好接上 galgame 式对话框背景 |
| **侧边的桌子** | 创作 / 建卡 | 玩家坐在 OC 对面,一边改设定一边**看到 OC 实时变化** |
| 手机 | 聊天系统 | 店里放一部手机 = 纯聊天入口(和角色单独聊天,纯聊天引擎副产物),独立于糖沐的商城对话 |
| 玩家的 CN | 玩家 avatar | 在店里走动(可选,玩家做了 CN 才有) |

几处要点:
- **糖沐 = 活的搜索 / 客服**:商城和搜索不做成列表筛选,而是和糖沐对话("有没有推荐的?")→ 她从书架 / 商城里给你拿。把冷功能变成有人格的交互。
- **侧门进游玩 → galgame 背景无缝**:进游玩正好接 galgame 式对话框背景(承接故事界面 + 视觉小说式涟漪转场)。
- **创作桌 · 坐在 OC 对面看实时变化**:建卡不是填表,而是面对面——改一句设定,对面的 OC 当场变。把"AI 解析 → 摆给用户看 → 确认 / 微调"的回环可视化成"AI 读懂了你的角色"的高光时刻。

# 二、沉浸式房间(原愿景版 · 完整)

第三阶段的视觉目标。一个第一视角的空间隐喻入口:加载动画是一只手推开门,用户走进一个房间,躺在懒人沙发上。之后基本都是角色第一视角,转场用角色移动 + 摄像机镜头移动来过渡。

房间陈设 → 功能映射:

| 房间里的物件 | 对应功能 |
|---|---|
| 书架(上面是买过 / 写过的书,按封面选书) | 书库 / 选书 |
| 选完书后的两种阅读法 | ① 视觉小说式:涟漪转场效果 + galgame 式角色对话框;② 传统式:小说页面变成"角色:内容"的排版 |
| 保险柜 | 充值系统(充钱就是把金币放进保险柜的感觉) |
| 书桌(桌上摊着一本书) | 创造卡片的界面 |
| 书桌上的画笔 | 生成图片的界面 |
| 沙发边小桌子上的书 | 上一次游玩的书 |
| 手机 | 聊天系统 |
| 点击角色 | 进入个人界面 |

另外内置一个"和这个虚拟角色聊天的 AI"做导航助手,比如帮用户找书之类。

---

# 三、两版对照(房间 → 书坊怎么演进)

- **房间 → 书店(书坊)**:从私人房间改成有店主、有客人的书店,更适合后期"商城 / 社交 / 被很多人逛过"的形态。
- **抽象 AI 导航助手 → 糖沐**(具象 CN,坐收银台)。
- **保险柜充值 → 收银台买咖啡(token)**。
- **书桌建卡 → 创作桌 + 坐 OC 对面看实时变化**。
- **书架选书 / 两种阅读法 / 手机聊天 / 点击角色进个人页** → 保留,见上两节。
- 书坊版新增:**玩家自己的 CN 在店里走动**、糖沐把"商城 + 搜索 + 充值"合成一处对话。

- 实现路径:第三阶段重活(分镜 → AE → Three.js)。早期先用现有扁平 UI,沉浸版后做。
