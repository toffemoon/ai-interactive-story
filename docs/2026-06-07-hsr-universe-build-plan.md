# 崩坏:星穹铁道宇宙 · 构建计划

> **目标(主理人定)**:做一个**完整的崩铁分支** —— 完整的背景故事 + 角色设定 + 剧情,**玩家可以自由选择时间线进入**(从序章、雅利洛、罗浮、匹诺康尼任一节点开局)。
> 本文件只定**怎么建**(来源 / 数据分层 / 入口设计 / 落地路径),不含实际抄录的版权内容。

---

## 0. 版权立场

**非商用**前提下构建(同人/研究性质)。游戏内剧情对"完整还原"是必要的,所以会用到剧情文本来源;不做商用分发、不二次售卖。真要公开发布前再评估。

---

## 1. 来源分工(主理人拍板)

| 层 | 用什么 | 为什么 |
|---|---|---|
| **世界观 + 角色设定** | 智库 / Fandom / BWiki / 灰机 wiki | 结构化、条目化、社区维护全;适合抽成世界书条目 + 角色卡 |
| **游戏内剧情(对白/分支)** | GitHub **StarrailDialog**(剧情对白数据) | 原文级剧情,做"完整剧情还原"必须有 |
| 官方 | **几乎不用** | 官方资料零散、非结构化,不适合直接喂引擎 |

> 取舍理由:wiki 类来源已经把"世界观/角色"做成了条目,直接对齐引擎的世界书/角色卡;而"游戏内剧情"wiki 覆盖不全、不成原文,所以剧情走 StarrailDialog。

---

## 2. 数据分层(对齐引擎的卡片体系)

引擎的内容单元 = 角色卡 / 世界书 / 故事书 / 玩家卡 / 事件卡。崩铁宇宙按三层组织:

```
L0  共享世界书(整个崩铁宇宙通用,所有弧都挂它)
      宇宙观、命途(Path)、星神(Aeon)、主要势力(星穹列车/星核猎手/仙舟/家族…)、关键名词表
        ↓ 复用
L1  开拓队 crew(跨弧稳定角色)
      开拓者(=玩家可扮)、三月七、丹恒、姬子、瓦尔特、黑塔…  → 角色卡(带 versions:按进度的人格/信息层)
        ↓ 进入
弧 Arc(= 一个可独立开局的"时间线入口")
      每弧 = 故事书(背景+主线) + 本弧专属角色卡 + 事件卡 + 一个开局预设(preset)
      ├── 序章(空间站黑塔 / 列车启程)
      ├── 雅利洛-VI(贝洛伯格 / 大公 / 杰帕德 / 布洛妮娅…)
      ├── 仙舟罗浮(罗浮 / 景元 / 刃 / 镜流 / 丹恒·饮月…)
      └── 匹诺康尼(白日梦酒店 / 黑天鹅 / 砂金 / 帝皇…)
```

**复用关系**:L0 世界书所有弧共享;L1 crew 出现在多弧(用角色卡的 `versions` 表达不同进度的认知/剧透层);每弧再补本弧专属角色 + 事件。

---

## 3. "自由选择时间线进入" 怎么落地

- **每个弧 = 一个故事预设(preset)**,即一个独立开局入口。玩家选时间线 = 选哪个 preset 开局。
- 开局时装载:**L0 世界书 + L1 crew(取该弧对应 version)+ 本弧故事书/角色/事件**。
- **剧透分层靠角色卡 `known_hidden`/`versions`**(见 P0 提案 `decisions/2026-06-06-角色卡-known_hidden-versions-注入提案.md`):同一角色在"序章版"和"匹诺康尼版"知道的事不同,引擎按选定弧注入对应信息层 → 玩家从早期时间线进入时不会被后期剧情剧透。**这条是本计划对引擎的硬依赖(P0)。**

---

## 4. 构建在确定性导入器上

复用 Yufei 的 `scripts/import_story.py` / `scripts/import_amphoreus.py`(《如我所书》《翁法罗斯》已验证的路子):固定模板 → 引擎**确定性解析**入库,**不走 LLM**(省钱、可复现、可 diff)。崩铁内容整理成同样的模板格式批量导入。

## 5. 分阶段落地路径

```
阶段 1(pilot,先打通一条竖切):
  L0 世界书 v0(命途/星神/势力/名词表)
  + L1 crew v0(开拓者 + 三月七 + 丹恒 + 姬子,带 version 字段)
  + 1 个弧(建议「雅利洛-VI」,剧情自包含、角色集中)
  + 该弧 preset 可开局
  → 用评测平台(eval/)跑 HSR 长测验证记忆/canon/知识边界(对标 M2 的 65 轮基线)

阶段 2(铺开):
  补齐序章 / 仙舟罗浮 / 匹诺康尼 三弧 + 各自专属角色/事件
  完善 versions 剧透分层(依赖 P0 引擎能力落地)

阶段 3(打磨):
  跨弧一致性、时间线选择 UI、玩家可扮角色(playables)扩展
```
