# 账户系统上线 —— 给 Yufei 的变更说明

> 账户系统 + 账户中心已进 main(PR #41 / #42 / #43)。**默认 `AUTH_ENABLED=0`,行为与之前逐字节一致**;
> 但它**改了 cards / presets / sessions 的数据模型**,你以后碰卡库 / 导入 / 前端存档 / operator 时会遇到,先同步给你。

## 一句话
邮箱验证码 + 密码登录;super / admin / user 三级角色;**每个人的会话 / 卡库 / 预设按 `user_id` 隔离**;operator 控制台改成"账户中心"。

## 你最可能踩到的:cards / presets 模型变了
- 两表都加了 **`user_id`** 列:**`NULL` = 官方公共**(所有人只读可见)、**非 NULL = 某用户私有**。
- 唯一性**不再是全局 `unique(kind,name)`**,改成**部分唯一索引**:
  - `uq_cards_official` = `unique(kind,name) WHERE user_id IS NULL`
  - `uq_cards_user` = `unique(user_id,kind,name) WHERE user_id IS NOT NULL`
  - presets 同理。
  - ⚠️ **别再加回全局 `unique(kind,name)`**(会让"用户卡与官方同名"冲突 → 打破隔离;PR #44 就是这个,已关)。
- `storage.save_library` / `save_preset` 用 **`on conflict … where …`**(对准 cards/presets 的部分唯一索引、单语句原子 upsert;`storage.py:185-194 / 268-277`);之前 import 报的 `on conflict 缺约束` 已不会再出现。 *(2026-06-15 更正:此前本行误写为 "update-then-insert",代码实为 on conflict。)*
- **你的导入器(`import_story.py` / `import_amphoreus.py`)不用改**:`save_library(kind, name, payload)` 默认 `user_id=None` → 入**官方公共库**,正是你要的(官方故事/卡所有人可见)。

## sessions 归属
- `sessions` 加 `user_id`;玩 / 读 / 删走 `auth.authorize_session`(`AUTH_ENABLED=0` 时全 no-op,不影响你现在)。
- 续玩仍从 `data.artifacts` 还原卡组(没变);**OC 分发 = 给用户开一局归属是他的存档**,他在「我的存档」直接续玩。

## 前端(你改 app.jsx 注意这些新增区域)
- 顶部加了 **`window.fetch` 包装**:有登录 token 时自动给所有 `/api` 请求带 `Authorization`。
- 新增 **LoginView**(`AUTH_ENABLED=1` 且未登录时全屏拦登录)、TopNav 用户/退出、**MineView 登录后存档走 `/api/my/sessions`**(跨设备)。
- StoryPanel 加了「↓ 回到底部」按钮。
- operator 控制台抽到了独立文件 **`operator_console.html`**(不再内联在 `api.py`),改成"账户中心 + 自带登录 + 角色显隐"。

## 登录 / 角色 / 开关
- 注册 = 邮箱 + 邮箱验证码 + 密码;登录 = 邮箱/用户名 + 密码;token 60 天、可登出吊销。
- 角色:`super`(.env `SUPERADMIN_EMAIL` 钉)/ `admin`(super 在账户中心一键提)/ `user`。
- 开关 env:`AUTH_ENABLED` / `SUPERADMIN_EMAIL` / `AUTH_TOKEN_PEPPER` / `SMTP_*`(发码 Gmail SMTP;没配且 AUTH 开 = 503 fail-closed,绝不泄漏码)。
