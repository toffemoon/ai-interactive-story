# 创作画板二期:真画布(Lovart 形)× 块-动作模型(template 骨)—— H 系列

> **一句话**:把 G 系列的"固定挂版"升级成真画布(pan/zoom/工具栏/相机),交互内核对齐 template 已验证的块-动作模型——**卡=画布上的块;手势走抽象层;信号画在卡上、是一等可点对象;聚焦用相机推进实现,弹窗退役**。
>
> 流程语义(understand 门控/装订/发布)本期一律不动——主理人拍板"先不用在意流程";本计划只动空间与交互模型。

## 0. 为什么(承接)

- G3 收尾账如实写明:一期固定视口,pan/zoom/框选/连线留二期——本计划即二期,主理人 2026-07-12 拍板形态:Lovart/Figma 大画布 + 工具栏。
- template Act 2 的四根可迁移柱子(07 计划 + act2 回望账,gate 全绿已验):①块模型+手势抽象层是地基;②窄路径纪律(一种块×一个动作先证明 select→act→inline-apply,loop 即复用模板);③信号画在块上、一等可交互;④每阶段 gate 全绿才进下一阶段。另有 Act 2.5 血泪账:功能真≠可用,叙述层决定用户懂不懂。
- 2026-07-12 会话内对 C→G 链做过对抗验证预审:画板一族缺陷(跨台闭包误删/下标当 key/层级倒挂/Esc 双关等)与本计划的地基决策同根,H 系列按 §3 就地根治;不属画板范畴的其余预审项(onUpload 确认缺失、genIntro 并发、酒馆导入类型校验、E6 手机门控样式等)**另开修复批次,不混进 H**。

## 1. 四个架构决策(已按默认写,反对早说)

- **【D1】视口引擎自研,零依赖。** world 容器吃 `translate+scale`,屏幕↔世界坐标唯一换算函数;滚轮对准光标缩放(0.25–2),Space/中键/触控板 pan;**pan/zoom 每帧 ref 直写 + rAF,不过 React state,松手才 commit**(G1 现在每 move 一次 setState 的写法到 pan 会卡)。不引 react-flow/tldraw/konva:体积 45kB+ 起、与纸墨 token 皮肤打架,且它们送的连线/minimap 正是 template【D2】说的"没确认需要就别建"。自研核心约两百行。
- **【D2】稳定 id 地基先行(P0 精神)。** built 卡在收进本台时生成稳定 id(老数据一次性迁移补 id);boardPos/boardSel/boardFocus 全部挂 id 不挂数组下标;视图状态迁移到 `ais_create_board_v2`(读不到或格式不对=整体丢弃回锚区自动落位,回滚=删一个键)。下标族 bug 机械性消失(见 H0)。
- **【D3】聚焦=相机推进,不是弹窗。** 双击卡→相机动画推到该卡居中、缩放正好 1.0→F8 字段画布 JSX 原地复用直接可编辑;Esc/点空白=相机拉回;built 聚焦=同路只读。overlay 层整个退役,z-index 倒挂/Esc 双关/内外两套状态那族问题连根消失;编辑永远发生在 scale=1,文本模糊与输入光标怪癖天然不存在。reduced-motion=跳切不动画。
- **【D4】BoardActionTrigger 手势抽象层(照抄 template P0)。** 上层组件只订阅"哪张卡被触发(cardId, 触发型:select/enter/context)",不认具体手势。桌面=单击选中+选中后浮出上下文工具条(替换 hover 即现的小钮——hover 误触族的根)+双击进入;触屏=长按,留接口不实现。将来手机上不上画布,只动这一层。

## 2. 块型×动作矩阵 + 信号 + 叙述层

| 块型 | 上下文动作(选中即见) | 卡面信号(一等可点) |
|---|---|---|
| 草稿·构思中 | 聚焦构思 / 挂资料 / 丢弃 | 朱砂呼吸点;完整度火候线(点击直达圈选) |
| 草稿·落笔中 | 聚焦编辑 / 引用 / 收进本台 / 导出 | busy 墨点;fresh 墨晕摘要;蓝图待批徽(点击直达批准) |
| 成品 built | 查看 / 改编成草稿 / 引用 / 导出 / 移除 | 成品书脊标 |
| 空白画布 | 双击=四卡种快速落卡;工具栏拖出落卡 | 空板三扇门引导(沿用,重排) |

**叙述层上画布(L0 + Lovart 姿势)**:AI 最新一句以批注笺锚在活动卡旁,busy=卡面墨点;构思期的追问/圈选/蓝图本就长在卡面(F8 muse),相机模式下板级天然可见——「板级构思不可见」断点用空间方案顺带解决,不碰流程。

**布局**:左侧工具 rail(V 选择 / H 抓手 / 四卡种落卡工具);顶部 boardbar 瘦身成文件级(装订/发布/对话/菜单);底部 dock 浮岛=AI 命令条(位置不动);右下角缩放控件(%,适配全部,100%)。

## 3. 切片(H0–H7,每片 gate 全绿才进下一片)

- **H0 地基**:稳定 id + 视图状态 v2 迁移;吸收预审下标族修复——removeBuilt 跨台误删(Create.jsx:1486)、exportCard 不传 bc.kk(:1485)、boardPos 下标 key 漂移(:361)、boardSel 不随增删同步(:1846)。DoD:四个 bug 的复现步骤全部不再复现;老 localStorage(v1 坐标/无 id built)无缝。
- **H1 视口引擎**:pan/zoom/世界坐标/持久化/右下缩放控件。DoD:任意缩放级别拖卡落点精确;pan/zoom 全程零 React 重渲(Profiler 证据);刷新后视口与卡位复原。
- **H2 窄路径(P1 精神)**:BoardActionTrigger + 上下文工具条,先只挂**一个动作(引用)**跑通 select→act→inline-apply(选卡→工具条→引用→纸签落 dock,墨晕反馈)。DoD:该 loop 端到端真调;hover 小钮退役;拖后 click/dblclick 抑制、pointercancel 兜底随本片落(:1469/:408 预审项)。绿了才铺满矩阵其余动作(含改编后选中语境迁移,:1484)。
- **H3 工具栏**:左 rail + 快捷键(V/H/Space/⌘0 适配全部/1-4 落卡)+ boardbar 瘦身。DoD:纯键盘可完成选卡→落卡→适配全部;rail 与 dock 无遮挡冲突。
- **H4 相机聚焦**:退役 G3 focus overlay,双击推进/Esc 拉回,F8 字段画布原地复用可编辑;z-index 倒挂(Create.css:2309)与 Esc 双关(:1143)随 overlay 退役消失。DoD:聚焦态内✎/⟳/✦/圈选/蓝图批准全链路真调可用;Esc 只逐层退(编辑→聚焦→选中);抽屉/弹层在聚焦态可正常交互。
- **H5 信号上卡**:火候线/蓝图待批徽/busy 墨点/批注笺全部可点直达处置动作(P2 精神:信号=一等可交互对象)。DoD:构思中卡不聚焦也能从卡面信号直达圈选/批准;批注笺随活动卡锚定。
- **H6 空白起草**:双击空白落卡/工具拖出落卡/文件拖进画布=按位置导入。DoD:三入口真调各走通一次;误触(拖拽经过空白)不落卡。
- **H7 回归收尾**:手机 390 零泄漏、reduced-motion 清单、性能账(build 体积与 07-11 基线对比)、全链路冷加载回归、PR。

**明确二期不做**(等真实用户信号,template D2 纪律):框选多选、卡间连线、minimap、无限画布分区、触屏手势实装。

## 4. 红线(每片都守)

- **零后端改动**(H 系列纯前端);API 契约与 desks localStorage 数据形状不动——**板永远是投影**,视图状态只住 `ais_create_board_v2`。
- 手机 `.ct` 分支零改动;零新 npm 依赖;视觉全语义 token(纸/墨/朱砂/鎏金);`.env` 不读写;不直推 main。

## 5. 风险(如实)

- 浏览态非整数缩放文本略糊(编辑态 scale=1 已规避;浏览态可接受,Figma 同病)。
- 触控板 pinch 与页面滚动手势冲突:`ctrl+wheel`=缩放、裸 wheel=pan 约定收口,H1 实测定案。
- 无头 preview 验收:screenshot 30s 超时是本环境已知,验收走几何度量+DOM 断言+交互脚本(同 C→G 历轮口径)。
- 相机推进与 React 状态切换的时序(聚焦中收进本台/切台)是 H4 最大坑位,DoD 里全链路真调必须覆盖。
