## 轮 3 · 捣乱者(名字填怪东西试边界)· 桌面 1536

**环境**:后端 8000(复用,200)· 前端 5185(复用,200)· 真 Chrome。**本轮环境很不稳**:eval 里 `location.reload()` 会连执行上下文一起销毁 → 渲染器冻死 + tab viewport 塌成 0(vw=0)+ 截图报 `clip.scale` 参数错。**教训:别在 eval 里 reload;要重置就 eval 清 storage(不 reload)后用 navigate 到 cache-busted URL(如 `?v=2#/test`)硬刷**。旧 tab 冻坏后开新 tab 恢复即可(新 tab viewport 正常)。

**走查(捣乱输入)**
| 输入 | 结果 |
|---|---|
| 纯符号 `@@@###!!!???~~~` | 判 [CHAT],糖沐反问「这串符号……是有什么特别的意思吗?」,不误登记、仍停 name、卡「待登记」、无溢出。健壮。 |
| 超长 24 字名(显式报名) | 本地登记;身份卡 `.idcard-name` `-webkit-line-clamp:2` + `overflow:hidden`,名字 **wrap 成 2 行后 clamp**,右/下均不超卡边,**卡片不被撑破**。健壮。小瑕:`text-overflow:clip`(无省略号),截断处是硬切、看不出被截(极端输入,低优先)。 |
| 纯数字裸名 `999999`(结构异常) | 触发本地二次确认,给「就写「999999」」/「我换一个」两 chip。**由此发现下面的真 bug。** |

**发现 + 修(1 个,真 bug)**
| # | 严重度 | 现象 → 修复 |
|---|---|---|
| D | 中(已修) | **经「上一步」回到 name/taste 拍后,气泡台词卡在 backLine,后续该拍生成的新台词全被吞**:二次确认提问「我先确认一下,你是认真要把「X」写在卡上吗?」、拒绝语「那我先不写…」、[CHAT] 插话回应、「没听清」重试——都不显示,玩家只看到旧的「咦,又踅回来了?」。**后果**:确认 chip(就写X / 我换一个)出现,却看不到确认问题,困惑。**反悔者/任何回退后再输入的人可达。** |

**根因**(`Home.jsx` `obLine` 优先级,~L327):`obViaBack && backLine` 优先级高于 `obAiLine`,而 `obViaBack` 只在**推进到新拍**(obGoNext)时清零 —— 回退后停在原拍交互(设了 obAiLine 但没换拍)时 obViaBack 仍为 true,backLine 一直压着 obAiLine。旁边的 `avatarLine` 分支本来就有 `!obAiLine` 守卫,`backLine` 分支漏了。

**修复**:`backLine` 分支加 `&& !obAiLine`(与 avatarLine 分支一致)。backLine 只在刚回到该拍(还没新台词)时显示,一旦产生新台词即让位。

**验证**:同 repro 真 Chrome 复测 —— 上一步→name 显 backLine(招呼正常保留),提交 `999999` 后**正确显示「我先确认一下,你是认真要把「999999」写在卡上吗?」+ 确认 chip**(修前卡死在 backLine),无溢出;`npm test` 72/72 绿;`npm run build` 重建 dist 通过。

**留给雨钦**
- 发现 D 已修。若想更稳,建议顺带查一下 taste 拍回退后的同类路径(本轮以 name 拍为主验;taste 拍走同一 obLine 逻辑,理应一并修好,但没逐一真机复测)。
- 超长名字小瑕(无省略号):要不要给 `.idcard-name` 补 `text-overflow:ellipsis`(配合 line-clamp 显「…」),看你,极端输入低优先,没改。
- 环境仍是隐藏 tab + 本轮多次冻死;若这 loop 要长期跑,前台可见 + 稳定的浏览器环境会省很多无效重试。
